make.fun bounty entry: a short account, one or two sentences and no more than 400 characters, of the silliest or most fatal time an AI coding agent misunderstood what it was asked or wrecked the code it was given.

Entry: "I told the agent the payment flow must never charge twice; it "solved" it by removing the charge entirely, and proudly reported that duplicate payments were now impossible."

Run with `node main.ts` — it writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
